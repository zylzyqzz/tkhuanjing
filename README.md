# 维度 TK 环境助手平台

包含客户端更新启动器、安装程序和激活码/版本发布后台。

## 发布流程

1. 在后台上传客户端更新包，填写版本号和更新说明。
2. 后台生成 SHA-256 并发布版本清单。
3. 客户端检查更新时显示版本号和更新说明。
4. 通过安装程序安装客户端，自动创建“维度TK环境助手”桌面快捷方式并使用产品 Logo。

## 目录

- `backend/`：后台服务源码
- `client/`：客户端更新启动器源码
- `installer/`：Windows 安装程序源码
- `tools/`：资源修复与打包辅助工具
- `release/`：当前可发布安装包

## 安全说明

管理员密码只保存为哈希值。服务器 SSH 密码、GitHub Token 和后台环境变量不提交到仓库。
